pgdir_walk: returns the pte of the virtual memory. when we create a page table page, we use page_alloc, because page and page table page are both 4kb. Since the lower 12 bits are 0 (12 bits offset for a page), we use them to store information for the entry. for pde or pte, they store the physical address of the referene to next level.
